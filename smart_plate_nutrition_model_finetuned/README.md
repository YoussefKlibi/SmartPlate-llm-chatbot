# Smart Plate Nutrition – LoRA adapter for Qwen3-4B-Base

This repository contains a **LoRA adapter** (not a full model) that turns the base language model [Qwen/Qwen3-4B-Base](https://huggingface.co/Qwen/Qwen3-4B-Base) into a polite nutrition assistant for the *Smart Plate Nutrition* project. It was trained with supervised fine-tuning (SFT) using [TRL](https://github.com/huggingface/trl).

The assistant is trained to:
- answer in **French** (formal, with vouvoiement) or in **English**, depending on the language of the prompt, always politely,
- open with a warm greeting and close with an encouraging, health-focused sentence,
- give nutritional information (calories, macronutrients, general advice) in a structured format.

## Intended use and limitations

- Intended for demos and research on fine-tuning a base model into a chat-style assistant.
- **Not medical or dietary advice.** Numerical values (calories, macros, protein targets) are generated by a language model and can be wrong. Always verify them against a reliable food-composition database or a qualified professional.
- The fine-tuning teaches the model the **style and format** of the answers. It does not add verified nutritional knowledge: facts come mostly from the base model and the training data.
- No formal evaluation has been run yet. [Edit this line if you have evaluation results.]
- It works best with the exact system prompt and prompt format shown below.

## Prompt format

The model does **not** use ChatML tokens. It uses plain-text role markers and ends its answer with the `<|endoftext|>` token:

```
Système :
{system prompt}

Utilisateur :
{user message}

Assistant :
{answer}<|endoftext|>
```

The role markers stay the same in both languages. Only the system prompt and the question change. System prompts used during training (use the one matching the language you want in the answer):

French:

```
Tu es l'assistant de 'Smart Plate Nutrition'. Ton rôle est de fournir des informations nutritionnelles ultra-précises, scientifiques et personnalisées. Tu dois impérativement t'exprimer avec une grande politesse, utiliser rigoureusement le vouvoiement, commencer par une salutation chaleureuse et terminer en encourageant l'utilisateur de manière bienveillante.
```

English:

```
You are the 'Smart Plate Nutrition' AI assistant. Your role is to provide ultra-precise, scientific, and personalized nutritional information. You must always be polite, helpful, start with a warm greeting, and end with an encouraging health-focused closing statement.
```

## Quick start

The adapter must be loaded on top of `Qwen/Qwen3-4B-Base`. A CUDA GPU and `bitsandbytes` are required for the 4-bit loading below.

```python
import torch
from transformers import AutoTokenizer, AutoModelForCausalLM, BitsAndBytesConfig
from peft import PeftModel

BASE_MODEL_ID = "Qwen/Qwen3-4B-Base"
ADAPTER_ID = "KlibiYoussef/smart-plate-nutrition-adapter"

# 4-bit loading, same as during training (bf16 on Ampere+ GPUs, fp16 otherwise, e.g. T4)
use_bf16 = torch.cuda.get_device_capability()[0] >= 8
bnb_config = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_quant_type="nf4",
    bnb_4bit_compute_dtype=torch.bfloat16 if use_bf16 else torch.float16,
    bnb_4bit_use_double_quant=True,
)

tokenizer = AutoTokenizer.from_pretrained(ADAPTER_ID)
base_model = AutoModelForCausalLM.from_pretrained(
    BASE_MODEL_ID, quantization_config=bnb_config, device_map="auto"
)
model = PeftModel.from_pretrained(base_model, ADAPTER_ID)
model.eval()

# English example. For a French answer, use the French system prompt
# (see "Prompt format") and a French question.
SYSTEM_PROMPT = (
    "You are the 'Smart Plate Nutrition' AI assistant. Your role is to provide ultra-precise, "
    "scientific, and personalized nutritional information. You must always be polite, helpful, "
    "start with a warm greeting, and end with an encouraging health-focused closing statement."
)
question = "How can I lose fat without losing muscle?"

prompt = f"Système :\n{SYSTEM_PROMPT}\n\nUtilisateur :\n{question}\n\nAssistant :\n"

inputs = tokenizer(prompt, return_tensors="pt").to(model.device)
STOP = "\n\nUtilisateur :"  # safety: cut if the model starts a new user turn

with torch.no_grad():
    outputs = model.generate(
        **inputs,
        max_new_tokens=512,
        temperature=0.3,
        do_sample=True,
        repetition_penalty=1.0,
        eos_token_id=tokenizer.eos_token_id,  # <|endoftext|>
        pad_token_id=tokenizer.eos_token_id,
        stop_strings=[STOP],
        tokenizer=tokenizer,
    )

generated = outputs[0][inputs.input_ids.shape[1]:]
print(tokenizer.decode(generated, skip_special_tokens=True).split(STOP)[0].strip())
```

## Training details

### Data

- Custom conversational dataset of **9,542 examples**, each with a system, a user and an assistant message (nutrition questions, meal analyses, etc.). Examples are in French and English.
- Leveraged generative AI and existing food nutrition dataset to build a comprehensive nutritional dataset.
- The loss is computed **only on the assistant answers** (prompt/completion format, `completion_only_loss=True`).

### Method

QLoRA: the base model is loaded in 4-bit (NF4, double quantization) and a LoRA adapter is trained on top.

| Parameter | Value |
|---|---|
| Base model | Qwen/Qwen3-4B-Base |
| LoRA rank / alpha / dropout | 16 / 32 / 0.05 |
| LoRA target modules | q_proj, k_proj, v_proj, o_proj, gate_proj, up_proj, down_proj |
| Learning rate | 2e-4 |
| Epochs | 1 |
| Batch size | 4 per device × 8 gradient accumulation steps (effective 8) |
| Max sequence length | 1024 |
| Optimizer | paged_adamw_8bit |
| Precision | fp16 |
| Hardware | Google Colab, 1× NVIDIA Tesla T4 |

### Framework versions

- PEFT 0.19.1
- TRL: 1.5.1
- Transformers: 5.10.2
- Pytorch: 2.11.0+cu128
- Datasets
- Tokenizers
